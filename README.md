# OwerPlay Créditos

Gestor mobile-first para controle de compras, saídas e revendas de créditos Uniplay e GOAT.

## Primeira versão
- Dashboard SaaS mobile-first
- Histórico inicial de setembro/2026 pré-carregado
- Cadastro, edição e exclusão de movimentações
- Compras Uniplay/GOAT
- Revendas Uniplay (Dayana/Ranon)
- Saídas para clientes/operação
- Caixa de reposição com regra de R$ 10 por crédito
- Meta visual de R$ 375 para lote de 50 Uniplay
- Persistência local no navegador via localStorage

Nesta primeira fase os dados ficam salvos no navegador/aparelho.
